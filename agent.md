# 🎨 Success Together Academy - Design System

## 🌿 Color Palette (Aesthetic & Calm)

### 🟣 Primary – Soft Indigo
- **Hex:** `#4B5DFF`
- **RGB:** `rgb(75, 93, 255)`
- **Feel:** Intelligence, creativity, calm confidence
- **Usage:** Header, sidebar, active menu items, primary buttons, links
- **Accessibility:** WCAG AA compliant for text on white backgrounds

### 🌱 Secondary – Sage Green
- **Hex:** `#9DB8A0`
- **RGB:** `rgb(157, 184, 160)`
- **Feel:** Growth, balance, peace, harmony
- **Usage:** Progress bars, success states, course status indicators, completed items
- **Accessibility:** Best used for backgrounds and borders, not primary text

### 🤍 Background – Warm Cream
- **Hex:** `#F6F4F1`
- **RGB:** `rgb(246, 244, 241)`
- **Feel:** Soft, cozy, eye-friendly, warm
- **Usage:** Main background, card backgrounds, section backgrounds
- **Accessibility:** Excellent contrast for dark text

### 🌸 Accent – Blush Peach
- **Hex:** `#F2B5A7`
- **RGB:** `rgb(242, 181, 167)`
- **Feel:** Friendly, gentle motivation, warmth, approachable
- **Usage:** CTA buttons, highlights, active states, hover effects, notifications
- **Accessibility:** Use with dark text for readability

### 🖋 Text – Charcoal
- **Hex:** `#2E2E2E`
- **RGB:** `rgb(46, 46, 46)`
- **Feel:** Soft black, easy reading, professional
- **Usage:** Primary text, headings, body content
- **Accessibility:** High contrast on light backgrounds

### Additional Colors

#### Text Light (Secondary Text)
- **Hex:** `#6B7280`
- **Usage:** Secondary text, placeholders, captions

#### White
- **Hex:** `#FFFFFF`
- **Usage:** Card backgrounds, button text, icons on colored backgrounds

#### Border Color
- **Hex:** `#E5E7EB`
- **Usage:** Borders, dividers, subtle separators

#### Success Green
- **Hex:** `#10B981`
- **Usage:** Success messages, completed states

#### Error Red
- **Hex:** `#EF4444`
- **Usage:** Error messages, delete actions, warnings

## 🔤 Typography System

### Font Pair (Very Important for Aesthetic)

#### Headings
- **Primary:** `Poppins` (Modern, geometric, friendly)
- **Alternative:** `Playfair Display` (Elegant, serif for special headings)
- **Weights:** 600 (Semi-bold), 700 (Bold)
- **Usage:** Page titles, section headers, card titles

#### Body Text
- **Primary:** `Inter` (Clean, readable, modern)
- **Alternative:** `Nunito` (Rounded, friendly, approachable)
- **Weights:** 400 (Regular), 500 (Medium)
- **Usage:** Paragraphs, descriptions, form inputs

### Font Sizes
- **H1:** 2.5rem (40px) - Page titles
- **H2:** 2rem (32px) - Section headers
- **H3:** 1.5rem (24px) - Subsection headers
- **H4:** 1.25rem (20px) - Card titles
- **Body:** 1rem (16px) - Default text
- **Small:** 0.875rem (14px) - Captions, labels
- **Tiny:** 0.75rem (12px) - Fine print

### Line Heights
- **Headings:** 1.2 (Tight, impactful)
- **Body:** 1.6 (Comfortable reading)
- **Small text:** 1.5 (Balanced)

## 🚀 Implementation Notes

### CSS Variables
All colors are defined as CSS custom properties in `src/index.css`:
```css
:root {
  --primary-color: #4B5DFF;
  --secondary-color: #9DB8A0;
  --accent-color: #F2B5A7;
  --bg-color: #F6F4F1;
  --text-color: #2E2E2E;
  /* ... */
}
```

### Usage
Always use CSS variables instead of hardcoded colors:
```css
/* ✅ Good */
color: var(--primary-color);
background: var(--bg-color);

/* ❌ Bad */
color: #4B5DFF;
background: #F6F4F1;
```

### Responsive Design
- **Mobile-first** approach
- Breakpoints: 480px, 768px, 1024px, 1280px
- Touch-friendly targets (min 44x44px)

### Accessibility
- Minimum contrast ratio: 4.5:1 for text
- Focus indicators: 2px Soft Indigo outline
- Keyboard navigation: Full support
- Screen reader: Semantic HTML
